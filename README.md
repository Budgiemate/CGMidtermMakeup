# CGMidtermMakeup
intro to cg midterm makeup

world reflection shader
added world reflection shader to give a sort of parralax effect to make the background move believably as well as added an hdr color to make the background glow and look like lave light

moving tile shader 
added moving tile shader to simulate lava flowing underneath the ground the player is standing on. This was done to make the player be more careful and stay on the safe ground
